# Стартовий проєкт SIS-LAB02

1. Відкрийте проєкт у GitHub Codespaces (Code → Codespaces → Create codespace) або локально: `python3 -m venv .venv`, `source .venv/bin/activate`, `pip install -r requirements.txt`. Права адміністратора не потрібні, зовнішня мережа для роботи не потрібна.
2. Визначте свою задачу й набір за номером варіанта: задача = `(номер - 1) // 3 + 1`, набір = `(номер - 1) % 3 + 1`. Реалізуйте код у файлі `variants/lab_NN.py` за карткою варіанта.
3. Запускайте відкриті тести своєї задачі й свого набору: `pytest tests/test_lab_NN.py -k S2` (замініть `S2` на свій набір: `S1`, `S2` або `S3`).
4. Змінюйте лише свій файл у `variants/` (і за бажанням додавайте `tests/test_my.py`). Час і «випадковість» у коді беріть лише з параметрів `clock` і `rng`.
5. Частина Б: підберіть параметри в `part_b/params.json`, дивіться показники командою `python part_b/experiment.py`, перевіряйте вимоги командою `pytest part_b`, а пояснення запишіть у `part_b/ANSWERS.md`.
